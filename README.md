Installation and use of the "Concert Castanets" SounFont (virtual instrument)  for MuseScore 4.5.2 and 4.6.0, til 4.6.3

The delivered .zip file contains:
a) all the files to produce the sound of the "Concert Castanets"
b) installation guide i.e how and where to install the required files
c) The User guide or manual for the different uses of the instrument
d) An example of a score using the instrument in MuseScore 4.5.2, the .mp3 playback and the .pdf score.

The documentation is in Spanish, German and English 

The soundFonts, configuration and examples files are contained in the "Wiki" tab.

The soundFont, documentation, score templates and Castanets (voices) work have been created by Maria P.Guerra García ( juli 2025)

The 2 new SoundFonts Concert_Castanets_Mezzo_Kit_2026.sf2 and Concert_Castanets_Alto_Kit_2026.sf2 are added to the existing one Concert_Castanets_Kit.sf2.
The purpose of them is to provide different Castanets timbres (semi-low and low-pitches) 

Installation and use of the new "Concert Castanets" SounFonts (virtual instrument) created for MuseScore ver.4.0.0 through 5.0.0
which produce semi-low and low-Castanets timbres.

The delivered .zip file contains:
a) all the files to produce the sound of the "Concert Castanets" for semi-low timbre (Concert_Castanets_Mezzo_Kit_2026.sf2) and
low-timbre (Concert_Castanets_Alto_Kit_2026.sf2)
b) installation guide i.e how and where to install the required files
c) An example of a score using the instrument in MuseScore 4.7.5, the .mscz file, the .mp3 playback and the .pdf score.

The documentation is in Spanish, German and English 

The soundFont, documentation and score has been created by Maria P.Guerra García ( September 2026)
